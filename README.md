# Project Doctor

### A health check for your coding projects.

Project Doctor is a Windows developer tool built with Python that scans coding projects for common problems, security issues, dependency problems, and project-structure issues.

Select a project, run a scan, and quickly see what needs attention.

## Features

| Feature             | Description                         |
| ------------------- | ----------------------------------- |
| Code Scanner        | Finds common coding problems        |
| Security Scanner    | Detects possible exposed secrets    |
| Dependency Checker  | Finds dependency problems           |
| Project Structure   | Checks project organisation         |
| Large File Detector | Finds unusually large files         |
| Duplicate Finder    | Finds duplicate files               |
| Health Score        | Gives your project an overall score |
| Safe Fixes          | Helps fix certain problems          |
| Local-First         | Your project stays on your computer |

## How It Works

### 1. Select Your Project

Choose the coding project you want to analyse.

### 2. Scan

Project Doctor examines the project files and checks for potential problems.

### 3. Review

Problems are organised by category and severity.

### 4. Fix

Use the available fixes after reviewing the changes.

---

## Privacy

Project Doctor is designed to work locally on your computer.

Your source code and project files are not uploaded to external servers by Project Doctor.

Detected secrets are masked in scan results.
