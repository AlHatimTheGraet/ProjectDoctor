# Project Doctor

Project Doctor is a Windows developer tool that scans coding projects for common problems.

## Features

- Detect coding problems
- Detect possible exposed secrets
- Check dependencies
- Check project structure
- Find large files
- Find duplicate files
- Generate a project health score
- Provide safe fixes
- Local-first — your code stays on your computer

## Supported Platform

- Windows 10
- Windows 11
